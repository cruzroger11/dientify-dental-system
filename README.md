# 🦷 Dientify — Sistema de Gestión Dental

Dientify es una plataforma web integral diseñada para la administración y gestión clínica de consultorios odontológicos.

## 🚀 Módulos del Sistema
- **Dashboard Maestro**: Métricas clave y resumen operativo.
- **Gestión de Pacientes**: Expedientes generales e identificación única.
- **Expediente Clínico Unificado**: Historial médico, diagnóstico, archivos adjuntos y generación de reportes en PDF.
- **Odontograma Digital Interactivo**: Mapeo anatómico por superficies (FDI) para dentición permanente (adultos) e infantil (temporal) con exportación en PDF.
- **Planes de Tratamiento & Presupuestos**: Cotización dinámica de procedimientos, cálculo automático de totales e impresión.
- **Agenda Multivista de Citas**: Filtros temporales (*Esta Semana*, *Próxima Semana*, *Este Mes*), semáforo de estatus y recordatorios automáticos por WhatsApp.
- **Gestión de Usuarios & Personal Médicos**: Control de acceso para odontólogos tratantes, administradores y recepcionistas.

## 🛠️ Tecnologías Utilizadas
- **Frontend**: React.js, Tailwind CSS, Lucide Icons.
- **Backend / Base de Datos**: Supabase (PostgreSQL, Storage, RLS).
